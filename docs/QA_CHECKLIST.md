# Checklist de QA y aceptación

## Frontend
- [ ] Responsive en móvil/tablet/escritorio.
- [ ] Formularios, validaciones y estados loading/error/vacío.
- [ ] Navegación y accesibilidad por teclado.

## API y datos
- [ ] Validaciones, códigos HTTP, paginación y límites.
- [ ] Unidades, fechas, rangos, historial y correcciones.
- [ ] Migraciones Alembic reproducibles.

## Seguridad
- [ ] Aislamiento entre usuarios y roles.
- [ ] Consentimiento vigente y revocación.
- [ ] Sesiones, rate limiting, carga maliciosa y almacenamiento privado.

## IA y 3D
- [ ] Pose parcial, mala calidad, repetibilidad y versión del modelo.
- [ ] GLB válido, escala, wireframe, LOD, rendimiento móvil y fallback.
- [ ] Licencias verificadas.

## Operación
- [ ] Build, logs, alertas, backups y restauración.
- [ ] Pruebas de integración y checklist de release.
